| 현관에서 거실로 전환 | 현관에서 누적된 낙상 후보·방문자·택배 상태가 이어지지 않음 |

| 후보 상태에서 뒤척임/수평 이동 | 낮은 형태 관측이 충분하면 정지 없이 의심 이벤트; 관측 부족이면 2.5초 만료 |
| 앉기·숙이기·의도적으로 눕기 | 영상별 오탐 여부와 박스 형태 기록; 모든 정상 동작 구분을 보장하지 않음 |

| 같은 동작을 거리·처리 간격을 달리해 입력 | 허용 관측 간격 안에서 시간·크기 기준이 유지되는지 확인 |
