## 시스템 역할

카메라 영상은 Pi의 `vision.vision_pipeline`이 처리한다. YOLO는 영상에서 사람의 위치를 검출하는 모델이며, 검출 결과를 낙상·침입·방문자 판정에 사용한다. 택배는 사람이 떠난 뒤 배경과 달라진 물체를 비교해 판정한다.

```text
Picamera2 → YOLO / 감지기 → EventRecorder → EventEmitter → Render → Supabase
                    ↕
              AVShare (마이크 영상 요청·오디오 공유)
```

`EventEmitter`는 이벤트와 첨부를 로컬 전송 대기열에 저장하고 서버로 전송한다. 카메라 서비스는 최신 프레임을 보관해 하트비트와 현재 화면 캡처 요청도 처리한다. 백엔드는 Pi가 아니라 Render에서 실행된다.

## 현재 코드 상태

- 카메라 설정: 640×480, 목표 5 FPS. 실제 추론 처리 속도는 Pi에서 확인 필요.
- 현재 로컬 코드의 거실 모드: 경비 ON/OFF 모두 낙상을 감지하고 침입은 ON에서만 감지한다. 현관 모드: 경비와 무관하게 방문자·택배 감지. 이전 문서의 “ON은 침입만”과 달라 현재 코드 기준으로 정정했다. 이번 낙상 알고리즘 수정에서 모드 정책은 변경하지 않았다. 의도한 정책 및 Pi 반영 상태는 **확인 필요**.
- 침입: 연속 3프레임 사람 검출, 같은 출현 중 중복 억제, 5프레임 미검출 후 재감지 준비. 장소·경비 상태는 `DetectionModeState`가 동일한 하트비트 응답으로 함께 적용한다. 별도 `GuardModeClient`는 main에서 사용하지 않는다. 갱신 주기는 기본 20초 + 요청 시간이며 최초 정상 응답 전에는 새 영상 감지 이벤트를 만들지 않는다. 통신 실패·불완전 응답은 마지막 상태를 유지한다.
- 낙상(2026-10-12): 최근 0.8초 안에서 기준 높이 25% 초과 중심 하강, 초당 기준 높이 0.5배 이상 속도를 요구한다. 기준 가로/세로 비율은 0.8 이하. 이후 높이 65% 이하 **또는** 가로/세로 비율 0.9 이상이면서 기준의 1.5배 이상이면 후보다. 미탐 우선으로 두 자세 조건을 모두 요구하던 규칙을 완화했다.
- 낙상 의심 확정: 낮은 형태를 실제 관측한 시간 합계 0.8초 이상, 최소 3회 관측. 뒤척임·수평 이동은 허용한다. 후보 만료는 2.5초. 미검출은 마지막 관측 후 1초까지 보존하되 미검출을 사이에 둔 구간과 0.6초 초과 처리 공백은 관측 시간에 더하지 않는다. 1초 초과 공백, 잘못된 박스, 시간 역전/중복, 중심 높이 회복은 초기화한다. `movement_ratio`는 호출 호환용이며 판정에 사용하지 않는다.
- 택배(2026-10-12): 방문 중 사람 영역의 합집합과 물체 ROI 안에서 동일 위치·크기 변화 영역을 확인한다. 퇴장 확인 후 최대 10초 동안, 2초 이상 및 최소 3회 연속 관측 시 의심 이벤트. 파이프라인 최소 프레임 수를 10에서 3으로 바꾸되 2초 조건을 추가했다. 사람 퇴장 자체는 기존 5회 미검출 기준이다. 입력 프레임 누락·1초 초과 처리 공백·물체 소실·재등장은 후보 누적을 끊는다. 균일한 전체 밝기 변화는 픽셀 차이의 중앙값으로 보정한다. 실행 검증은 미완료다.
- 택배 물체 영역 `DELIVERY_OBJECT_ROI`를 사람 확인 영역 `DOOR_ROI`와 분리했다. 두 영역 모두 현재 전체 화면이며 실제 설치 화면의 바닥 좌표로 전자를 조정해야 한다. `DeliveryDetector(object_roi=None)`은 기존처럼 `roi`를 물체에도 사용한다. 바닥 영역 밖에 사람 중심이 있어도 방문을 추적할 수 있다.
- 일반 영상은 기본 감지 전후 각 3초를 녹화한다. 소리 이벤트의 영상 요청도 같은 녹화기를 사용한다.
- 2026-10-09 로컬 수정: 녹화 중 후속 이벤트를 종류별로 보관하고 저장된 클립으로 각각 전송한다. 침입·낙상은 경비 상태별로 분리하며 전환 전에 이미 감지한 이벤트는 보존한다. 같은 종류는 클립당 첫 감지만 유지한다. 기존 전송 쿨다운은 유지한다.
- 장소/경비 전환 시 낙상 이력·대상을 초기화하고 방문자·택배는 장소 전환 시에만 초기화한다. 낙상의 기존 `history_frames`·픽셀 임계값 인자는 시간·비율 인자로 교체했고 `backup_pipe.py`의 생성 호출도 맞췄다.
- `FallPersonTracker`는 한 명을 추적한다. 박스 겹침 외에 이전·현재 모두 단일 인물인 경우 이전 높이의 75% 이내 중심 거리로 연결한다. 1초까지 미검출 대상을 보존하고, 대상 변경·장기 소실·모호한 겹침은 초기화한다. 가까운 다른 사람으로의 오연결과 다인 장면 미탐은 남는다.
- 원본 영상·썸네일은 정상 큐 저장 또는 의도적인 쿨다운 제외 시 정리한다. 큐 저장 예외 시 원본을 보존하고 오류를 전달한다. 보존된 원본의 자동 재등록은 구현하지 않았다.
