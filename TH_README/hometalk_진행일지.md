### 결정과 이유

- 우선순위가 낮다는 이유로 위험 이벤트를 버리지 않도록 종류별 보관을 선택했다. 같은 종류는 클립당 첫 감지만 유지해 메모리를 제한한다.
- 녹화기 하나를 유지하고 같은 영상을 공유해 카메라 사용 방식과 전송 인터페이스 변경을 줄였다. 기존 전송 쿨다운은 유지한다.
- 모드 전환 전 감지 이력은 새 모드의 상황과 맞지 않을 수 있어 감지기와 택배 배경을 초기화한다.

- 요청 범위: vision 코드를 수정하고 edge 변경 필요 사항은 보고만 한다. 음성 감지·문열림·백엔드 코드는 수정하지 않는다.
