# HomeCare 영상 촬영 — 현장 2시간 매뉴얼

작성일: 2026-10-14. 목적은 실제 Pi 카메라의 원본 영상을 수집하고, 돌아와 이벤트 알고리즘을 평가하는 것이다. 현장에서 임계값 수정·배포·정확도 평가는 하지 않는다.

## 장면별 정답 표시 (2026-10-15)

아래는 **매뉴얼대로 촬영했을 때의 목표 정답**이다. 실제 영상 내용을 확인한 라벨이 아니며, 촬영이 다르게 됐다면 실제 행동을 보고 수정한다. 같은 시나리오의 R1/R2에는 같은 기준을 적용한다. 감지기의 현재 한계 때문에 놓치더라도 정답을 음성으로 바꾸지 않는다.

- O: 해당 이벤트가 나와야 함. X: 해당 이벤트가 나오면 오탐. 보류: 실제 동작/평가 범위를 먼저 확인.
- F 계열: 거실·경비 OFF로 평가해 낙상만 확인한다.
- I 계열: 거실·경비 ON으로 침입을 평가한다. 경비 OFF로 재평가하면 침입은 전부 X다.
- V/D 계열: 현관으로 평가한다. 경비 ON/OFF와 관계없이 방문자·택배를 확인한다.
- 아래는 감지 규칙의 정답이다. 전송 쿨다운·녹화 공유에 따른 서버 이벤트 수는 별도로 평가한다.

| 파일 앞부분 | 실제 연기 | 주 평가 이벤트 | 정답 | 함께 발생해도 정상인 이벤트 / 주의 |
|---|---|---|---|---|
| F01_R… | 옆으로 모의 낙상 | 낙상 | O (모의 낙상 목표) | 안전 연출만 담긴 자료로 실제 사고 성능과 구분. 천천히 의도적으로 누운 영상이면 별도 분류 |
| F02_R… | 다른 방향의 모의 낙상 | 낙상 | O (모의 낙상 목표) | F01과 동일. 안전을 위해 더 빠르게 연기하지 않음 |
| F03_R… | 천천히 주저앉기 | 낙상 | 보류 | 힘이 풀리는 사고를 연출했으면 위험 동작 양성, 평소처럼 의도적으로 앉았으면 음성. 현재 설명만으로 확정하지 않으며 본 점수에서 우선 분리 |
| F04_R… | 의자에 앉았다 일어나기 | 낙상 | X | 정상 동작. 거실·경비 OFF에서는 다른 영상 이벤트도 없음 |
| F05_R… | 물건 줍기 | 낙상 | X | 정상 동작 |
| F06_R… | 의도적으로 앉고 눕기 | 낙상 | X | 실제 코드가 낙상으로 잡아도 평가상 오탐 |
| I01_R… | 입장 후 머무름 | 침입 | O | 한 번의 출현에 1회 목표. 가족도 동일한 경비 정책 적용 |
| I02_R… | 짧은 통과 | 침입 | O (사람 출현) | 방문자와 달리 머무름 불필요. 극히 짧은 노출은 경계 사례로 분리; 현재 규칙은 연속 3회 검출을 요구 |
| I03_R… | 퇴장 후 재입장 | 침입 | O | 감지기 기준 2회 목표. 같은 클립 공유·30초 전송 제한으로 서버에는 2건이 안 남을 수 있음 |
| I04_R… | 사람 없이 문/조명 변화 | 침입 | X | 실제로 사람이 보였다면 재분류 |
| V01_R… | 현관 앞 5초 대기 | 방문자 | O | 택배 X |
| V02_R… | 현관 앞 10초 대기 | 방문자 | O | 머무름 한 번에 1회 목표, 택배 X |
| V03_R… | 1–2초 짧은 통과 | 방문자 | X | 실제 체류가 길었다면 확인 필요. 택배 X |
| V04_R… | 먼 곳/가장자리 5초 대기 | 방문자 | O | 사람 중심이 평가 ROI 안에 있는 장면 기준. 택배 X |
| D01_R… | 큰 박스 놓고 퇴장 | 택배 | O | 사람이 충분히 머물러 방문자 O도 정상 |
| D02_R… | 작거나 배경색과 비슷한 박스 놓기 | 택배 | O | 어려운 양성 사례이며 놓쳐도 정답은 O. 방문자 O도 정상 |
| D03_R… | 가장자리/먼 바닥에 놓기 | 택배 | O | 평가 물체 ROI 안 기준. 방문자 O도 정상 |
| D04_R… | 빈손으로 머물다 퇴장 | 택배 | X | **방문자는 O**. 모든 이벤트가 없어야 한다는 뜻이 아님 |
| D05_R… | 기존 박스를 가져감 | 택배 | X | **방문자는 O**. 택배가 발생하면 추가/회수 구분 실패 |
| D06_R… | 빈손 방문 중 문/조명 변경 | 택배 | X | **방문자는 O**. 택배가 발생하면 배경 변화 오탐 |
| BG_R… | 앞 5분 빈 화면, 뒤 5분 통행 | 구간별 | 구간 분리 | 현관에서 빈 화면은 방문자/택배 X. 뒤쪽은 짧은 통과 X, 충분한 머무름은 방문자 O로 실제 행동별 라벨 |
| TEST_R… | 촬영 확인 | 평가 제외 | — | 구도/재생 확인용. 정식 정확도 계산에서 제외 |

택배 장면의 방문자 O는 원래 시간표처럼 사람이 충분히 화면에 머문 경우다. 실제 촬영이 매우 짧았다면 별도 확인한다. 현관 평가에서는 낙상·침입이 생성되면 안 되며, 거실 평가에서는 방문자·택배가 생성되면 안 된다.

**감지 안 됨 ≠ 정상:** F01/F02, D02/D03 같은 어려운 장면에서 감지가 안 됐다면 미탐일 수 있다. 반대로 D05 회수 장면에서 택배가 나오는 것은 현재 배경 차분 방식의 한계이지 올바른 정답이 아니다. 원본 영상과 실제 행동을 기준으로 라벨을 정한다.

### 처음 한 번 준비

기존 vision을 실행하던 Python 환경을 사용합니다. 먼저 Pi 터미널에서:

```bash
cd /homecare/vision
python3 -c "import cv2; from picamera2 import Picamera2; print('카메라 라이브러리 확인 OK')"
```

import 오류가 나면 기존 vision용 가상환경을 활성화한 뒤 다시 실행합니다. 새로 설치하지 않습니다. 카메라를 이미 쓰는 vision_pipeline이 터미널에서 실행 중이면 그 터미널에서 Ctrl+C로 종료합니다. systemd 서비스라면 확인된 해당 서비스만 중지하세요. 서비스 이름은 확인 필요이며, 이 스크립트는 다른 프로세스를 자동 종료하지 않습니다.

시험 촬영:

```bash
python3 record_dataset.py TEST
```

카메라 준비 후 **10초 카운트다운 → 15초 시험 촬영 → 자동 저장**합니다. REC가 표시된 순간부터 영상의 0초입니다. 0–5초 빈 화면, 5–10초 입장해 전신을 보이고, 10–15초 퇴장하세요. 저장한 MP4를 실제로 재생해 색·구도·속도를 확인한 다음 본 촬영을 시작합니다. 미리보기 창과 음성 안내는 없고, 터미널에 준비 카운트와 5초 간격 경과 시간이 출력됩니다. 신호음은 터미널 설정에 따라 들리지 않을 수 있으므로 촬영 담당자 또는 별도 타이머를 이용하세요.

### 모든 명령의 공통 동작

- 저장 위치는 기본적으로 **스크립트 옆 dataset 폴더**입니다. 위대로 복사했다면 영상과 JSON은 `/homecare/vision/dataset/`에 저장됩니다. 폴더가 없으면 자동 생성합니다.
- 예: `F01_R1_20261014_143000_123456_a1b2c3.mp4`. 같은 명령을 다시 입력하면 `F01_R2_...`로 저장됩니다. 날짜/시각은 Pi 시계를 사용합니다.
- 각 명령은 **한 번만 촬영**하고 종료됩니다. DONE 확인 → 자세/물건 정리 → 같은 명령 재입력으로 두 번째 촬영을 합니다. 아래 명령들을 한꺼번에 붙여넣지 마세요.
- 모든 시나리오에 기본 준비 시간 10초가 붙습니다. 더 필요하면 `python3 record_dataset.py F01 --countdown 20`처럼 실행합니다. 아래 시간표는 준비 시간이 끝난 REC부터 셉니다.
- 영상은 무음 640×480, 목표 15 FPS의 MP4(mp4v)입니다. 브라우저에서 재생이 안 되면 설치된 데스크톱 영상 플레이어로 확인합니다. 기존 알고리즘, YOLO, 이벤트 전송은 실행하지 않습니다.
- 같은 이름의 JSON도 생성됩니다. 촬영 상태·프레임 수·관측 FPS·프레임별 시각을 담으므로 MP4와 함께 보관하세요. 정답 라벨은 별도로 동작을 보고 작성합니다.
- Ctrl+C로 취소하면 부분 영상을 보존하고 JSON에 interrupted로 표시합니다. 정식 평가 영상으로 쓰지 말고 같은 명령으로 다시 찍으세요.
- 타이밍 경고가 나오면 영상의 재생 시간과 실제 동작 시간이 달라질 수 있습니다. 다른 부하를 줄이고 TEST부터 다시 확인하세요. 저장 완료 문구만으로 영상 품질을 보장하지 않습니다.
- 저장 폴더 권한 오류는 해당 폴더의 사용자 쓰기 권한을 확인합니다. sudo로 임의 실행하지 않습니다.

장면마다 파일을 끊기 어렵다면 이벤트별로 길게 녹화하고 각 연기의 시작·끝 시각을 메모한다. 시도 사이에는 아래 표의 빈 화면 시간을 확보한다. 현장에서 영상 편집은 하지 않는다.

## 3. 현장 도착 후 순서

1. 카메라를 실제 설치 위치에 고정한다. 높이·각도·카메라에서 연기 위치까지 거리와 조명을 기록하고, 설치 모습 사진을 남긴다.
2. 화면에서 사람의 머리부터 발끝, 누울 바닥과 박스 놓을 자리가 보이는지 확인한다. 촬영 담당자는 가능하면 화면 밖에 머문다.
3. 실제 감지 입력과 같은 640×480, 가로 방향을 우선한다. 녹화 도구가 지원하면 고정 15 또는 30 FPS로 원본을 보존한다. 고해상도 원본을 쓰면 동일한 4:3 화각을 유지하고 나중에 축소한다. 디지털 줌·미화·슬로모션·타임랩스는 사용하지 않는다.
4. 빈 화면 → 입장 → 5초 서기 → 퇴장으로 20초 시험 촬영한다. 저장을 끝낸 뒤 노트북에서 실제 파일을 열어 방향·색·재생 속도·누락 여부를 확인한다. 파일 복사도 한 번 시험한다.
5. 원본 저장 공간을 확인한다. 가능하면 시험 파일 용량/촬영 시간으로 필요한 공간을 추정한다. 실패하면 본 촬영 전에 해결한다.
6. 장면 ID를 메모하고 촬영한다. 음성이 녹음되면 시작 전에 ID를 말해도 되지만, 무음일 수 있으므로 파일/시각 메모를 반드시 남긴다. 안내판을 썼다면 치우고 빈 화면부터 다시 시작한다.
7. 촬영 중 앱 알림이 떴는지와 상관없이 계획한 연기를 마친다. 오프라인 평가용 원본 촬영에는 이벤트 쿨다운 5분을 기다릴 필요가 없다.

촬영 FPS와 실제 추론 FPS는 다르다. 현재 로컬 replay 도구는 영상 시각을 기준으로 목표 5 FPS를 샘플링한다. 이 원본만으로 Pi의 저장 중 감지 공백이나 업로드 지연을 검증할 수는 없다.

## 4. 낙상: 15–40분, 거실 구도

공통: 빈 화면 5초 → 입장해 똑바로 서서 3초 → 지정 동작 → 최종 자세 5초 유지 → 종료. 약 20–30초. 매트는 빈 화면을 찍기 전부터 설치한다.

**실제로 몸을 던지거나 앞으로/뒤로 쓰러지지 않는다.** 두꺼운 매트와 보조자가 있는 상태에서 낮은 자세부터 지지받아 옆으로 눕는 모의 동작만 한다. 서 있는 높이에서 안전하게 연결할 수 없으면 저자세 연출로 기록한다. 느린 안전 연출이 급하강 기준을 못 넘더라도 그대로 보관하고, 검출을 위해 더 위험하게 움직이지 않는다. 모의 영상은 실제 사고 영상과 구분한다.

| ID | 촬영 동작 | 기록할 정답/의도 |
|---|---|---|
| F01 | 몸 옆면이 보이도록, 지지받으며 옆으로 눕는 모의 낙상 | 모의 낙상, 자세 변화 확인 |
| F02 | 카메라를 비스듬히 바라본 상태에서 같은 안전 동작 | 모의 낙상, 방향 차이 |
| F03 | 천천히 무릎을 낮추고 바닥에 주저앉아 머물기 | 느린 주저앉음, 어려운 사례로 별도 기록 |
| F04 | 의자에 평소처럼 앉고 다시 일어서기 | 낙상 아님 |
| F05 | 바닥 물건을 허리/무릎을 굽혀 줍고 일어서기 | 낙상 아님 |
| F06 | 의도적으로 매트에 앉은 뒤 편하게 눕기 | 낙상 아님, 의도적 눕기 |

각 2회. 가능하면 첫 회는 중간 거리, 둘째는 조금 먼 거리에서 촬영하되 전신이 보이게 한다. F03은 실제 동작과 의도를 기록하고 나중에 평가 범주를 확정한다. 검출 여부를 보고 정답을 바꾸지 않는다.

## 5. 침입: 40–50분, 같은 거실 구도

공통: 빈 화면 5초 → 지정 동작 → 퇴장 후 빈 화면 5초. 약 20–30초. 영상만 촬영할 때 앱의 경비 설정을 매번 바꿀 필요는 없다. 나중에 같은 영상을 거실/경비 ON과 OFF로 각각 재생할 수 있다.

| ID | 촬영 동작 | 평가 의도 |
|---|---|---|
| I01 | 한 명 입장 → 5초 서기 → 퇴장 | 경비 ON에서 침입, OFF에서 침입 없음 |
| I02 | 한 명이 화면을 자연스럽게 가로질러 통과 | 짧은 출현의 검출 여부; 화면에 보인 실제 시간 기록 |
| I03 | 입장 → 3초 머무름 → 완전히 퇴장해 5초 대기 → 재입장 3초 | 두 번의 출현과 재감지 확인; 35–40초 촬영 |
| I04 | 사람이 안 보이는 상태에서 문 움직임 또는 조명 변화 | 사람 없는 장면의 오탐 확인 |

각 2회. 가족도 경비 ON에서 보이면 현재 정책상 침입 대상이다. 가족이라는 이유로 비침입 정답을 붙이지 않는다.

## 6. 방문자: 55–70분, 현관 구도

공통: 빈 화면 5초 → 지정 동작 → 완전히 퇴장 후 빈 화면 5초. 약 20–30초. 카메라를 옮겼다면 설치 사진과 거리 메모를 새로 남긴다.

| ID | 촬영 동작 | 평가 의도 |
|---|---|---|
| V01 | 접근 → 현관 앞에서 5초 기다림 → 퇴장 | 방문자 있음 |
| V02 | 접근 → 현관 앞에서 10초 기다림 → 퇴장 | 오래 머물러도 같은 방문 중 중복 발생 여부 |
| V03 | 멈추지 않고 자연스럽게 통과 | 짧은 통과; 실제 화면 체류 시간 기록 |
| V04 | 가장자리/먼 위치에서 5초 기다렸다 퇴장 | 작거나 일부 가려진 사람의 검출 확인 |

각 2회. V03은 1–2초 정도의 짧은 통과를 목표로 하되 뛰지 않는다. 화면에 오래 남았다면 긴 통과로 기록한다. 현재 사람 ROI는 전체 화면이므로 현관 문 앞이 아니어도 오래 보이면 방문자로 잡힐 수 있다.

## 7. 택배: 70–95분, 같은 현관 구도

**가장 중요한 것은 촬영 앞뒤를 자르지 않는 것이다.** 공통: 사람 없는 초기 화면 8초 → 입장·지정 행동 → 사람 완전 퇴장 → 그대로 최소 15초 더 녹화. 약 35–45초.

| ID | 촬영 동작 | 평가 의도 |
|---|---|---|
| D01 | 바닥과 대비되는 큰 박스를 중앙에 놓고 퇴장 | 물체 추가 있음 |
| D02 | 작은 박스 또는 바닥과 비슷한 색 박스를 놓고 퇴장 | 어려운 물체 추가 |
| D03 | 화면 가장자리/먼 바닥에 박스를 놓고 옆으로 걸어나감 | 물체 위치와 퇴장 위치 차이 |
| D04 | 빈손으로 들어와 잠깐 머물다 퇴장 | 물체 추가 없음 |
| D05 | 촬영 전부터 있던 박스를 입장 후 들고 퇴장 | 물체 회수, 새 택배 아님 |
| D06 | 빈손으로 입장해 문 상태 또는 조명을 바꾼 뒤 퇴장 | 물체 추가 없음, 배경 변화 오탐 확인 |

각 2회. D06 첫 회는 문 상태만, 둘째는 조명만 바꾸어 원인을 구분한다.

- D01–D03은 시작 전에 박스를 치우고, 사람 없는 배경부터 찍는다.
- D05는 **박스가 놓인 상태로 초기 8초**를 찍는다. 그래야 회수 전후를 비교할 수 있다.
- 놓은 박스는 퇴장 뒤 15초 촬영이 끝날 때까지 건드리지 않는다. 다음 촬영 전에 치운다.
- 사람은 몸 일부까지 화면 밖으로 완전히 나간다. 촬영 담당자도 화면 밖에 있어야 한다.
- 연속 파일이라면 박스 정리 구간을 메모하고, 다음 시도 전에 새로운 초기 배경 8초를 확보한다. 나중에 시나리오별로 나누어 평가한다.

## 8. 배경 영상: 95–105분

현관 구도를 유지하고 10분 연속 촬영한다. 앞 5분은 사람·물체 이동 없이 자연스러운 조명/그림자 변화를 담는다. 뒤 5분은 자연스러운 통행 등을 담되 시각을 기록한다. 머무름이 길면 방문자 정답이 될 수 있으므로 전체를 일괄 무사건으로 표시하지 않는다.

10분은 초기 오탐 점검용이다. 충분한 장시간 평가나 최종 정확도 근거로 간주하지 않는다. 촬영 뒤 10분 이상 여유가 생기면 같은 구도로 밝기 조건을 달리한 반복 영상을 우선 추가한다.

## 9. 파일 이름과 현장 메모

예: `20261014_S01_F01_R1.mp4` (날짜_세션_장면_반복). 실제 날짜와 실제 파일 확장자를 사용한다. 확장자만 mp4로 바꾸지 않는다. 길게 녹화했다면 원본 파일명과 각 시도의 상대 시각을 적는다.

최소 메모 양식:

| 파일/원본 | 장면·반복 | 행동 시작/끝(영상 내 초) | 실제 행동 | 거리 | 조명 | 특이사항 |
|---|---|---|---|---|---|---|
| 예: 20261014_S01_D01_R1.mp4 | D01-1 | 10–18초 | 박스 놓고 퇴장 | 약 2m | 실내등 ON | 퇴장 18초, 종료 35초 |

입장·낙상 동작·박스 놓기·완전 퇴장 시각은 가능하면 따로 적는다. 화면에 무엇이 있었는지를 기록하고 감지 결과를 정답으로 쓰지 않는다. 이 메모는 현장 수집용이며, 기존 평가 도구의 라벨 형식으로 변환하는 작업은 귀가 후 한다.

같은 날 같은 장소에서 반복한 영상은 우선 개발용 데이터로 취급한다. 비슷한 반복 영상을 임의로 개발/최종 시험에 나누지 않는다. 최종 시험용 독립 세션은 별도로 확보한다.

## 10. 철수 전: 105–120분

- [ ] 40클립 또는 시도 40개에 대응하는 연속 원본·시각 메모가 있는지 확인한다. 누락은 솔직히 표시한다.
- [ ] 네 이벤트 각각 최소 1개씩 처음·중간·끝을 재생한다. 택배는 초기 배경과 퇴장 후 15초, 낙상은 전신과 자세 변화가 실제로 찍혔는지 확인한다.
- [ ] 원본을 노트북/외장 저장장치로 복사하고 복사본도 재생한다. 원본은 삭제하지 않는다.
- [ ] 파일 개수·용량을 원본과 대조한다. 실패한 촬영도 구분해서 보관한다.
- [ ] 설치 사진, 조명·거리 메모, 파일 목록을 함께 가져온다.
